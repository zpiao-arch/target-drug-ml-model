# Model Artifacts

The full ExtraTrees model file is larger than GitHub's normal single-file limit when uncompressed:

- `models/target_match_drugcentral/extra_trees/target_match_extra_trees.joblib` (~193 MB)

For GitHub distribution, the complete package is provided as a Release asset:

- `target_drug_ml_model_package_20260601.zip`

After downloading and extracting the Release asset, the joblib file will be present in the expected path and `code/scripts/extra_trees_ranker.py` can run directly from the package root.
